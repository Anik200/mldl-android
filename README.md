# 📱 Mldl Android

> A modern, ultra-fast native Android application built with **Kotlin, Jetpack Compose, and Material You (Material 3)** to scan local music, download word-synced lyrics, and export them into Apple Music **.ttml**, **elrc**, and **.lrc** formats.

---

## ✨ Features

- 🎵 **Instant Local Music Scanner**: Super-fast batch folder indexing to scan all songs on your device.
- 🍏 **Apple Music-Like Lyrics (AMLL) Player**: Built-in full-screen dynamic lyric preview with active line focus, depth-of-field blur, sub-voice styling, and continuous syllable gradient sweeps.
- ⚡ **1-Click Batch Downloader**: Scan and download all missing lyrics across your entire library in parallel.
- 💿 **Album Batch Downloader**: Switch to the **Albums** tab to batch download full albums with one tap.
- 🎚️ **Display Scaling**: Easily adjust whole app layout and font sizes in Settings.
- 📁 **Identical File Naming & Backup**: Matches your music file name exactly (e.g. `song.flac` $\rightarrow$ `song.ttml`) and automatically archives existing lyric files to an `lrc/` subfolder.
- 💾 **Multi-Format Support**: Apple Music **TTML**, **Enhanced LRC**, **Standard LRC**, **SRT**, and **JSON**.
